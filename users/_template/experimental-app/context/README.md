# App context skeleton

No executable app or local server exists in this template.

Copy and fill the [app context template](../../../../context/templates/app-context.md)
here before developing a real app. Record model assumptions, sources, units,
setup, configuration, validation, known failures and the next action.

After copying this skeleton into `users/<member>/experimental-apps/<app>/`, the
relative path back to the repository's context templates gains one additional
`../`; update the link or replace this file with the filled template.
