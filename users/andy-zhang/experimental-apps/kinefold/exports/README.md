# Local exports

Project, equilibrium and dynamic JSON/CSV exports save in this app folder.
Kinefold displays the relative saved path after each export. Filenames include
a unique identifier so another export cannot overwrite a prior artifact.
Exports preserve the content supplied by each workspace; they do not certify
mechanical validity. Generated files are ignored by Git. Copy files from this
folder for portable backups or sharing; no browser Downloads folder is used.

The preset workspace also exports component/study bundles, sampled comparison
screens and captured batch results. A summary preserves component versions,
inputs, ranges and failures; individual job exports retain the engine output.
Import bundles through the preset workspace rather than the project importer.
