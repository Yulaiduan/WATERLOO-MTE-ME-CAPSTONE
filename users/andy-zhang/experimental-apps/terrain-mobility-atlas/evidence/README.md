# Reviewed legacy evidence

Selected original UI screenshots, terrain figures and small export evidence.
They illustrate the historical validation records and preserve original bytes.
Full original outputs, raw frame sets and large exports remain byte-preserved
in the sibling [Capstone archive](../../capstone-archive/README.md).

These are software-review artifacts and illustrative/observed profile figures,
not hardware results or canonical robot validation. See the app's import record
and source provenance before interpreting a figure.
