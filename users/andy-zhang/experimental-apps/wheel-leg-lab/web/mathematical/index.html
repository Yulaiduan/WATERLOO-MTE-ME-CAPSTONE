Independent mathematical model

Default input is prescribed wheel height in mm. A kinematic support imposes the step; chassis heave, velocities, accelerations and reaction forces are outputs. Chassis pitch stays fixed. J1 = hip, J2 = knee, J3 = wheel pin.

Pin forces and constraint couples are derived from instantaneous Newton–Euler balances after an independent SciPy energy-equation integration. They are not Pymunk impulse readings. The fixture is bilateral; an actual tire may lose contact when downward support would be required.

Finite smooth ramps provide continuous position, velocity and acceleration. Linear joins have velocity jumps and timestep-dependent force peaks. Force/torque impulse modes are retained only as explicit legacy diagnostics.

    Solver checks & model scope
    The physical grounded guide ratio is 2:1. In the chassis frame the links counter-rotate, so Pymunk uses an equivalent GearJoint with absolute ratio −1. Knee opening changes twice as fast as the link angle.
    SI internally: metres, kilograms, seconds, radians. Mathematical accelerations are analytic state derivatives; dt selects recorded output cadence. Travel events terminate before impact; no rigid-stop reaction is synthesized.
