# Pinned study inputs

Source: Jonathan Xie's experimental V4 solver at repository commit
`e91897a9cf9bb36ff3f20afc4c92ea5315cc46b7`. The HTML/model/verifier snapshot is
retained solely as a pinned numerical reference; it is not a second maintained
solver app. Current development belongs in Jonathan's original member workspace.

- `v4-textbook-10mm.json`: original 13 kg, zero-alpha, 8 N/mm, 10 mm-idler preset.
- `spring-reference.json`: 651 original embedded-library states, 100–165°.
- `screenshot-baseline.json`: October 19 8.75 kg/20° settings transcribed from
  Jon's solver image. Horn radius is rounded to its six displayed decimals.
- `v4-pulley.html`, `v4-model.md`, `verify-pulley.cjs`: pinned source and equations.

Lengths in the solver preset are mm, angles degrees, forces N, spring rate
N/mm. The dynamics port converts to SI. Reference preload is force at 90°;
it is not an installed spring length. No private screenshot/chat data is included.
The model note's four links to uncopied companion files point to their pinned
GitHub originals; numerical source and equations remain unchanged.
